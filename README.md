# Blog Application

This is a blog application that allows users to create, read, update, and delete blog posts. Users can sign up, log in, and interact with other users through comments and likes.

## Installation

1. Clone the repository.
2. Install the dependencies using `npm install`
3. Set up any necessary configuration files.

## Usage

1. Run `npm run dev` and `php run dev` commands to start the application.
2. Follow the prompts or instructions to sign up or log in.
3. Create a new blog post or view existing ones.
4. Interact with other users by commenting and liking posts.

## Database Configuration

1. Create a new database for your blog application. You can use any database management system supported by Laravel, such as MySQL, PostgreSQL, or SQLite.
2. Update the `.env` file in the root of your project directory with the appropriate database credentials. You can find the default values in the `.env.example` file.
